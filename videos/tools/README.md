# Інструменти для відео Небозводу

Короткі вертикальні відео (1080×1920, 30 кадрів/с) знімаються прямо з сайту: та сама сцена, текстури й шейдери.
Кожен кадр рендериться окремо з віртуальним годинником, тож рух ідеально плавний навіть на слабкому комп'ютері,
а повторний запис дає ті самі кадри (можна переробити лише шматок).

## Як зібрати відео

```bash
cd videos/tools
./make.sh saturn          # → videos/saturn.mp4
```

Потрібні Node.js із Playwright і Chromium (глобально), Python 3. `make.sh` сам поставить `three@0.147.0` (npm),
`pillow` та `imageio-ffmpeg` (pip). Повний запис 72-секундного відео триває ~10–15 хвилин.

Кроки окремо (проміжні файли — у `work/<сцена>/`, у git не потрапляють):

| Крок | Команда | Що робить |
|---|---|---|
| Кадри | `node rec.js saturn video [від до]` | рендерить кадри; з `від до` (секунди) — лише шматок |
| Розкадровка | `node rec.js saturn stills 5,20,40` | кілька окремих кадрів, щоб швидко глянути ракурси |
| Звук | `node audio.js saturn` | музика сайту + голос планети, відрендерені офлайн |
| Титри | `python3 compose.py saturn` | масштаб до 1080×1920, логотип, титри, заставка |
| Озвучка | `python3 voice.py saturn` | ріже запис голосу на фрази й ставить кожну під свій титр |
| Збірка | кінець `make.sh` | ffmpeg: H.264 + AAC, гучність −14 LUFS (стандарт соцмереж) |

Лише переозвучити готове відео (картинка не перезаписується, ~1 хвилина): `./make.sh saturn sound`.

## Озвучка

Запис голосу лежить у теці сцени (`scenes/saturn/voice.mp3`), а в `scene.json` блок `narration` каже, що звідки
брати: `parts` — список `[від, до, де]`, де «від–до» — секунди фрази в записі, «де» — момент у відео (зазвичай початок
її титру). Межі фраз знаходяться за паузами (`ffmpeg … silencedetect`). Під голосом музика й голос планети
стишуються приблизно на 10 дБ. Сцена без `narration` збирається як раніше, лише з музикою.

## Як зробити нове відео

Скопіюйте `scenes/saturn` у `scenes/<назва>` і змініть три файли:

- **`scene.json`** — дата на сайті, швидкість часу (`rate`: індекс зі шкали сайту, 2 = 1 год/с), тривалість,
  голос планети та коли він звучить (`audio`), а також `patches` — заміни в коді сайту лише для запису.
- **`cam.js`** — сценарій камери. `SHOTS` — список планів `[початок, кінець, функція]`: функція отримує
  `k` від 0 до 1 і повертає, де камера (`pos`) і куди дивиться (`look`). `__sceneSetup` готує сцену після
  завантаження (наприклад, справжня вісь Сатурна й місце Титана).
- **`captions.py`** — титри (`hook` — великий гачок угорі, `cap` — підпис унизу), склейки з затемненням
  (`CUTS`), час фінальної заставки й її заголовок.

Логотип «Небозвід», шрифти й фінальна заставка («посилання в профілі», «автор: lord-xay») спільні для всіх відео
й задаються в `compose.py`.
