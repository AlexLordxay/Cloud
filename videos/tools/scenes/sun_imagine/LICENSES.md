# «А ти уявляєш Сонце так?» — матеріали

- Сонце: повністю власна візуалізація (sunk.py, arches.py): грануляція, плями, потемніння до краю, протуберанець, петлі
  й корона змодельовані за даними NASA (розміри, температури), без чужих знімків.
- Атмосфера Землі: власний розрахунок розсіювання Релея й Мі (earthk.py).
- Земля: текстури сайту (planetarium/textures/earth) — NASA Blue Marble (день), NASA Black Marble (ніч); хмари — сайт.
  Збираються в work/sun_imagine/*.npy скриптом textures.py (у git не йдуть).
- Соняшники: власна 3D-модель поля (flowers.py).
- Планети на терезах: текстури сайту (Solar System Scope, CC BY 4.0).
- Зоряне тло (Чумацький Шлях, розмите): ESO/S. Brunier, «The Milky Way panorama» (CC BY 4.0); зорі — процедурні.
- Голос: автор (ElevenLabs v4 через Higgsfield, 3,22 кр.). Музика й звуки — синтезовані (music.js, synth_sfx.py).
