## Не вдалося отримати / обмеження

- `alice_event.jpg` (опційно) — **немає**: `cds.cern.ch` вимагає proof-of-work перевірку на бота (не обходив); на Commons підходящої події ALICE Pb-Pb (CC BY) не знайдено.
- `upload.wikimedia.org` тимчасово блокував вихідний IP (HTTP 429, Retry-After 600 с) для **оригіналів**; стандартні мініатюри (≤3840 px) віддавалися. Тому для файлів з Commons (`sun_visible`, `sand_grain`, `lamp_filament`, `andromeda`, `holmdel_horn`, `red_blood_cells`) використано найбільшу доступну мініатюру, а не оригінал (зазначено в таблиці). Оригінали можна підтягнути пізніше за прямими URL.
- NCI Visuals Online (`visualsonline.cancer.gov`) та `eoimages.gsfc.nasa.gov` були недоступні з мережі (502 / reset); NASA Black Marble взято через `images-assets.nasa.gov`.
- `casA_elements.jpg` — не окремі карти Si/S/Ca/Fe, а одна кольорова композитна карта Chandra (Fe/Si+S/Mg+Ne), низька роздільність даних.
- `planck_cmb_equirect.npy` — SMICA-nosz, колонка `I_STOKES_INP` (з заінпейнченою площиною Галактики; у площині — статистично згенерована реалізація, не реальний сигнал). Явного ліцензійного тексту на PLA/IRSA не знайдено (pla.esac.esa.int повертав 503). Рекомендується завжди давати acknowledgement.
- Повнорозмірний `planck_cmb_equirect.npy` (134 МБ) не комітиться (ліміт 50 МБ) — у `.gitignore`; у git лежать `planck_cmb_equirect_4096x2048.npy` та скрипт `planck_convert.py` для відтворення. Локальна копія може зникнути разом із середовищем.
- Орієнтація Planck-карти: l = 0…360° зліва направо (у класичних Mollweide-картах l зростає вліво — при потребі віддзеркалити).
- Усі файли у git ≤ 50 МБ (найбільший `hudf.jpg` ≈ 28 МБ).
