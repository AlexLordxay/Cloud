# Планетарій

Інтерактивна 3D-модель Сонячної системи на Three.js.

## Запуск

Текстури завантажуються як окремі файли, тому сторінку треба відкривати через вебсервер, а не подвійним кліком:

```bash
cd planetarium
python3 -m http.server 8000
# відкрийте http://localhost:8000
```

## Що є в моделі

- Сонце й 8 планет, кільця Сатурна й Урана.
- 16 супутників: Місяць, Фобос, Деймос, Іо, Європа, Ганімед, Каллісто, Енцелад, Рея, Титан, Міранда, Титанія, Оберон, Тритон, Харон.
- 5 карликових планет: Церера, Плутон, Хаумеа (з кільцем і витягнутою формою), Макемаке, Ерида — на нахилених еліптичних орбітах.
- Пояс астероїдів і пояс Койпера.

Розміри й відстані не в масштабі.

## Джерела текстур

- Сонце, Меркурій, Венера (атмосфера), Земля (день), Місяць, Марс, Юпітер, Сатурн і його кільця, Уран, Нептун — [Solar System Scope](https://www.solarsystemscope.com/textures/), ліцензія [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), на основі даних NASA.
- Хаумеа, Макемаке, Ерида — Solar System Scope (CC BY 4.0), умовна поверхня: детальних знімків цих тіл немає.
- Іо, Європа, Ганімед, Каллісто, Енцелад, Рея, Титан, Міранда, Титанія, Оберон, Тритон, Плутон, Харон, Церера — глобальні мозаїки NASA / JPL / USGS (місії Galileo, Voyager, Cassini, Dawn, New Horizons), суспільне надбання. Частину сірих мозаїк тоновано до приблизного кольору; незняті ділянки заповнено рівним тоном.
- Фобос і Деймос — умовна текстура (карта Місяця).
- Нічні вогні Землі, маска океанів і хмари — [приклади three.js](https://github.com/mrdoob/three.js/tree/dev/examples/textures/planets).

Текстури зменшено й перестиснено для вебу.
